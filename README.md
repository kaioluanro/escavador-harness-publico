# Escavador Harness

Evolução experimental do Escavador: estrutura em Python para ingestão, indexação e busca conversacional em diários oficiais. Projeto em desenvolvimento.

Esta versão pública não inclui acervo, dados de avaliação nem documentos originais. Consulte `pyproject.toml` para as dependências. O funcionamento completo depende de corpus e configurações fornecidos pelo usuário.
